# Kaun Banega Codepathi — Audio Assets Directory

Place your audio files here in `public/audio/`:

1. `KBC_Count_down_45sec.mp3` — Plays during 45s countdown (Questions 1 to 5)
2. `KBC_COUNT_DOWN_60 sec.mp3` — Plays during 60s countdown (Questions 6 to 10)
3. `kbc_answer_locked-in.mp3` — Plays immediately when the host locks the answer
4. `kbc-suspense.mp3` — Plays looping background suspense between locking and revealing
5. `kbc-right-answer.mp3` — Plays when the answer is revealed as correct
6. `kbc-wrong-answer.mp3` — Plays when the answer is wrong or on timeout

The sound engine will automatically load and play these files in exact sync with the countdown timer and host controls.
